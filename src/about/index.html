About the Beam app

Beam is a new generation browser allowing you to browse the web, capture the content you like, write down your thoughts and publish them. The Beam company is based in Paris, France.

What will this app do with user data?

The only user data received is: email and optionally calendar data. Email will be used to identify the user. It will be saved and re-displayed to the user. Calendar data is used only by the macOS application if the user agrees to it.

How does this app enhance user functionality?

This app is a new generation browser turning a pure read web experience into a read/write one.
